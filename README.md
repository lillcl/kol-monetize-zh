# KOL Monetize

給 KOL 的變現診斷。13 題、5 分鐘，輸出一條 5 步變現路徑：具體產品、定價、平台、Day 1 該做什麼。

## 線上

- 首頁 — https://kol-monetize-zh.vercel.app
- 58 個變現案例 — https://kol-monetize-zh.vercel.app/ways.html

## 本機開發

```bash
cd kol-monetize && python3 -m http.server 8000
```

開 http://localhost:8000

## 結構

```
index.html          首頁 + 診斷引擎（單檔，無建置步驟）
ways.html           58 個變現案例
img/                人物照與商品圖（見 img/README.md）
.claude/launch.json 預覽用開發伺服器設定
```

沒有 npm、沒有 bundler、沒有依賴。兩個 HTML 檔直接跑。

## 診斷引擎怎麼運作

**證據加權**：每題標記 A/B/C/D 四級權重，答案加權後決定引擎判定。

| 等級 | 意義 | 權重 |
|---|---|---|
| A | 實際行為（已有人付費） | 1.0 |
| B | 需求訊號（粉絲明確要求過） | 0.7 |
| C | 內容訊號（內容已在示範這個） | 0.5 |
| D | 偏好（自己覺得可以） | 0.2 |

**分支**：第 1 題的內容主軸決定第 9 題問什麼——教學型問「你能教什麼具體技能」，生活型問「你最常出現的每日儀式」，IP 型問「你有沒有反覆出現的角色」。

**輸出**：7 種引擎（人格 / 生活方式 / 專業教學 / 審美編輯 / 信任推薦 / IP / 社群）之一為主引擎，各自有 5 步產品階梯，含具體定價、平台、Day 1 動作、文案範本、晉升條件。

## 貨幣

全部顯示港幣，匯率寫在 `FX` 常數（`index.html` 與 `ways.html` 各一份）：

```js
const FX={USD:7.84,EUR:8.93,GBP:10.38,JPY:0.0498,TWD:0.247};
```

原始貨幣保留在資料裡，滑鼠停留在價格上可看原價。改匯率只改這個物件。

## 數據誠信原則

網站上每個數字都標明性質：

- **reported** — 創作者、公司或媒體公開揭露
- **estimated** — 依公開數據推算，標明計算方式
- **未公開** — 查不到就不填

兩個刻意留白的地方：

1. **六位個案的個人淨資產全部未公開。** 網路上排名他們淨資產的內容農場都是編的數字，寧可留白。
2. **營收欄標「品牌營收」不是「個人收入」。** TALA 的 £6.2M、NAP TEA 的 NT$1.8億都是公司數字，不等於創作者實際拿到的錢。
